Dates

Each pipeline searches for planning tasks due within this range (inclusive). This workflow does not support single/specific dates — only a range.

Pipelines to run

Each pipeline looks for existing planning task(s) tagged for that type, due within the chosen range, then builds a parent task + subtasks from each match. A pipeline can create more than one parent task if multiple planning tasks fall in the range.
